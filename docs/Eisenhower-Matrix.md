# Eisenhower Matrix

## Do First — MVP
- Add assignment and exam grades.
- Calculate the current weighted course average.
- Calculate the grade needed on a future exam to reach a target final grade.

## Schedule — Future Features
- Support multiple courses.
- Save and load grades using files.
- Generate detailed grade reports and statistics.

## Delegate — Use Existing Libraries
- Use Java built-in sorting utilities when needed.
- Use Java built-in file handling.
- Use built-in formatting utilities.

## Eliminate — Out of Scope
- Graphical user interface and animations.
- Integration with Purdue grading systems or Brightspace.
- Online accounts, user profiles, and cloud synchronization.
