# Academic Grade Calculator

## Project Overview
The Academic Grade Calculator is a Java command-line application designed to help college students track their grades and understand their academic performance.

Students can enter assignment and exam grades, calculate their current weighted course average, and determine what score they need on a future exam to achieve a desired final grade.

## Minimum Viable Product (MVP)
The first version of the application will allow users to:
- Add assignment and exam grades.
- View their entered grades.
- Calculate their current weighted average.
- Calculate the grade needed on a future exam to reach a target final grade.

## Future Plans
Features planned for future versions include:
- Supporting multiple courses.
- Saving and loading grades using files.
- Generating detailed grade reports and statistics.

## Technology Stack
- **Language:** Java
- **Data storage:** ArrayList (initially stored in memory)
- **Input:** Java Scanner
- **Development environment:** IntelliJ IDEA or Visual Studio Code
- **Version control:** Git and GitHub
